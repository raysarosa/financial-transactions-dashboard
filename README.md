# 💼 Financial Transactions Dashboard – Power BI

This Power BI project analyzes financial transactions across Brazil, providing clear insights into income and expenses by state, customer behavior, and transaction patterns.

## 📊 Project Summary

This dashboard was designed to:
- Track total income and expenses
- Analyze transaction distribution over time
- Compare income and expenses across Brazilian states
- Classify transaction types (Pix vs. No_Pix)
- Understand customer activity levels and rankings

## 🔍 Key Metrics

- **Total Income:** R$333.98M  
- **Total Expense:** R$142.24M  
- **Total Transactions:** 475,639  
- **Average Transaction Amount:** R$1,001  
- **Active Customers:** 3,967  
- **Inactive Customers:** 30  

## 📌 Features

- 📍 **Geographic Overview**: Dual-map visualization of income and expense distributions by state
- 📆 **Monthly Trends**: Income and expense charts for each month of the year
- 🔄 **Transaction Type Breakdown**: Visual split between Pix and non-Pix operations
- 👤 **Customer Overview**: Ranking by total transaction amount, with individual income and expense details

## 📁 Files

- `final_project.pbix` – Power BI dashboard file

## 🛠️ Tools & Tech

- Power BI Desktop
- DAX for custom measures (e.g. normalized bubble scaling)
- Bing Maps / OpenStreetMap
- Clean and interactive slicers for dynamic filtering

## 🧭 How to Use

1. Download and open the `.pbix` file in Power BI Desktop.
2. Explore the slicers to filter by time, customer, or transaction type.
3. Hover over map bubbles or bar charts for tooltip details.
